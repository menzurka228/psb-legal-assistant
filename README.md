# Юридический ассистент ПСБ — Hack&Change 2026

ИИ-ассистент для юристов банка: отвечает на вопросы по базе нормативных документов (RAG),
ссылается на конкретные положения и обоснованно отказывается, если данных недостаточно.

## Запуск одной командой

```bash
cp .env.example .env   # впишите LLM_BASE_URL и LLM_API_KEY
docker compose up --build
```

Интерфейс: http://localhost:8000 (порт хоста — `PORT` в `.env`).
Документы базы знаний кладутся в `data/kb/` (txt, md, docx; подпапки допускаются).

## Архитектура

```
 Браузер (React + TS, Vite)          frontend/
   чат · кликабельные ссылки [n] · панель положений · просмотр документа с подсветкой
        │  POST /api/chat, GET /api/documents/{name}
        ▼
 Go-сервис (net/http, без внешних зависимостей)   backend/
   internal/api        HTTP API + раздача собранного фронтенда
   internal/assistant  поиск → порог релевантности (отказ без вызова LLM)
                       → промпт с правилами достоверности → только процитированные источники
   internal/kb         загрузка документов, нарезка на положения, BM25 (интерфейс Searcher)
   internal/llm        клиент OpenAI-совместимого API (DeepSeek)
        │
        ▼
 LLM: DeepSeek V4.1 Flash (API организаторов)

 submission/   Python-версия для автоматической проверки на платформе (solution.py)
```

Почему Python в `submission/`: платформа хакатона запускает ZIP со скриптом `solution.py`.
Логика (промпт, поиск, отказ) должна совпадать с Go-сервисом — при изменениях правьте обе версии.

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/health` | статус и размер базы |
| `POST` | `/api/chat` | `{"question": "...", "history": [{"role": "user", "content": "..."}]}` → `{"answer", "sources", "refused"}` |
| `GET` | `/api/documents` | список документов |
| `GET` | `/api/documents/{name}` | полный текст документа |

## Переменные окружения

| Переменная | Описание | По умолчанию |
|---|---|---|
| `LLM_BASE_URL` | OpenAI-совместимый endpoint модели | `https://api.deepseek.com/v1` |
| `LLM_API_KEY` | ключ API (не коммитить!) | — |
| `LLM_MODEL` | имя модели | `deepseek-v4.1-flash` |
| `LLM_TEMPERATURE` | температура генерации | `0.1` |
| `LLM_TIMEOUT_SEC` | таймаут запроса к модели | `60` |
| `TOP_K` | сколько фрагментов передавать в модель | `8` |
| `MIN_SCORE` | порог BM25 для отказа | `1.0` |
| `PORT` | порт на хосте | `8000` |
| `KB_DIR`, `STATIC_DIR`, `ADDR` | пути и адрес внутри контейнера | заданы в Dockerfile |

Модели платформы: DeepSeek V4.1 Flash (генерация), BAAI/bge-m3 (эмбеддинги),
Qwen3 Reranker 8B (реранкинг, опционально).

## Разработка без Docker

Нужны Go 1.23+ и Node.js 20+.

```bash
# бэкенд (из корня репозитория)
cd backend && KB_DIR=../data/kb STATIC_DIR=../frontend/dist go run ./cmd/server
```

```bash
# фронтенд с hot reload — http://localhost:5173, /api проксируется на :8000
cd frontend && npm install && npm run dev
```

```bash
# тесты
cd backend && go test ./...
```

## Сабмит на автоматическую оценку

```bash
cd submission
pip install -r requirements.txt
python solution.py input.json output.json   # формат сверить с примером организаторов
./make_submission.sh                        # → submission/submission.zip
```

## Порядок проверки основного сценария

1. Положить документы в `data/kb/`, заполнить `.env`, выполнить `docker compose up --build`.
2. Открыть http://localhost:8000, задать вопрос по базе — в ответе ссылки `[n]`; клик по ссылке подсвечивает положение справа, «Открыть документ» показывает его в полном тексте.
3. Задать вопрос вне базы — ассистент сообщает, что данных недостаточно (жёлтая плашка).

## Известные ограничения

- Поиск пока лексический (BM25 + грубый стемминг).
- PDF в Go-сервисе не читается — конвертируйте заранее в txt/md.
- Формат `solution.py` условный — сверить с примером организаторов.
