# Юридический ассистент ПСБ — Hack&Change 2026

ИИ-ассистент для юристов банка: отвечает на вопросы по базе нормативных документов (RAG),
ссылается на конкретные положения и обоснованно отказывается, если данных недостаточно.

## Быстрый запуск (Docker)

```bash
cp .env.example .env   # впишите LLM_BASE_URL и LLM_API_KEY
docker compose up --build
```

Веб-интерфейс: http://localhost:8000 (порт задаётся `PORT` в `.env`).

## Архитектура

```
вопрос + история диалога
        │
        ▼
 app/kb.py         поиск по базе знаний (сейчас BM25 по положениям: статьи / пункты)
        │
        ▼
 app/assistant.py  проверка достаточности найденного → отказ, если ничего не найдено
        │          → LLM с системным промптом (ссылки [n], учёт редакций, защита роли)
        ▼
 ответ + подтверждающие фрагменты → app/main.py (FastAPI) → app/static/index.html (чат)
```

| Путь | Назначение |
|---|---|
| `app/kb.py` | загрузка документов (txt/md/docx/pdf), нарезка на положения, поиск |
| `app/assistant.py` | логика ассистента, системный промпт, контроль достоверности |
| `app/main.py` | API: `/api/chat`, `/api/documents`, `/api/health` |
| `app/static/index.html` | чат + панель подтверждающих фрагментов и просмотр документа |
| `solution.py` | точка входа для автоматической проверки на платформе |
| `scripts/make_submission.sh` | сборка `submission.zip` для сабмита |
| `data/kb/` | база знаний от организаторов (кладётся вручную) |

## Переменные окружения

| Переменная | Описание | По умолчанию |
|---|---|---|
| `LLM_BASE_URL` | OpenAI-совместимый endpoint модели | — |
| `LLM_API_KEY` | ключ API (не коммитить!) | — |
| `LLM_MODEL` | имя модели | `deepseek-v4.1-flash` |
| `LLM_TEMPERATURE` | температура генерации | `0.1` |
| `KB_DIR` | папка базы знаний | `data/kb` |
| `TOP_K` | сколько фрагментов передавать в модель | `8` |
| `MIN_SCORE` | порог релевантности для отказа | `1.0` |
| `PORT` | порт на хосте | `8000` |

Используемые модели на платформе: DeepSeek V4.1 Flash (генерация), BAAI/bge-m3 (эмбеддинги),
Qwen3 Reranker 8B (реранкинг, опционально).

## Локальная разработка без Docker

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt pytest
uvicorn app.main:app --reload
pytest
```

## Сабмит на автоматическую оценку

```bash
python solution.py input.json output.json   # формат сверить с примером организаторов
./scripts/make_submission.sh
```

## Порядок проверки основного сценария

1. Положить документы в `data/kb/`, заполнить `.env`, выполнить `docker compose up --build`.
2. Открыть http://localhost:8000, задать вопрос по базе — в ответе ссылки `[n]`, справа фрагменты.
3. Задать вопрос вне базы — ассистент сообщает, что данных недостаточно.
